# Digital Risk Communication and Consumer Confidence: A Study on Crisis Response Effectiveness

## Project Overview

This repository contains the Python code and supporting materials used for the dissertation:

**"Digital Risk Communication and Consumer Confidence: A Study on Crisis Response Effectiveness"**.

The study examines how three dimensions of digital risk communication:

- Risk Communication Effectiveness (RCE)
- Response Timeliness (RT)
- Transparency (TR)

influence:

- Consumer Confidence (CC)

during crisis situations.

A quantitative research approach was adopted using questionnaire-based survey data collected from consumers who had experience with digital platforms and crisis-related communications.

---

# Research Objectives

The analysis was conducted to achieve the following objectives:

### Objective 1
Analyse respondents' demographic profiles and assess the current status of:

- Risk Communication Effectiveness
- Response Timeliness
- Transparency
- Consumer Confidence

### Objective 2
Examine whether Consumer Confidence differs across demographic groups such as:

- Gender
- Age
- Education
- Occupation
- Monthly Income

### Objective 3
Investigate the relationship between communication factors and Consumer Confidence.

### Objective 4
Evaluate the impact of communication effectiveness, response timeliness, and transparency on Consumer Confidence using regression analysis.

# Objective 4: Multiple Linear Regression

Multiple Linear Regression was used to assess the simultaneous effect of all communication variables on Consumer Confidence.

## Model Specification

Dependent Variable:

```text
Consumer Confidence (CC)
```

Independent Variables:

```text
Risk Communication Effectiveness (RCE)
Response Timeliness (RT)
Transparency (TR)
```

Regression Equation:

\[
CC = \beta_0 + \beta_1(RCE) + \beta_2(RT) + \beta_3(TR) + \varepsilon
\]

Python package:

```python
statsmodels.api.OLS()
```

---

# Regression Results

## Model Fit

| Statistic | Value |
|------------|---------|
| R² | 0.809 |
| Adjusted R² | 0.802 |
| F Statistic | 115.9 |
| p-value | <0.001 |

### Interpretation

The model explains approximately:

**80.9% of the variation in Consumer Confidence**.

---

## Coefficient Results

| Variable | Coefficient | p-value |
|-----------|------------|---------|
| Communication Effectiveness | -0.058 | 0.611 |
| Response Timeliness | 0.583 | <0.001 |
| Transparency | 0.477 | <0.001 |

### Interpretation

- Response Timeliness significantly increases Consumer Confidence.
- Transparency significantly increases Consumer Confidence.
- Communication Effectiveness was not statistically significant after controlling for the other variables.
